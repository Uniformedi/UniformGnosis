## Project Overview

This is a static content repository for **The Spiritual Codex — Volume I: Uniform Gnosis**, a book by Daniel Medina (Uniformedi LLC). It is deployed to **Cloudflare Pages** with no build step — push to `main` deploys automatically.

The book spans 14 chapters across 5 parts, culminating in the **SAIVAS** (Sentient AI Value Alignment Standard) framework for identity-based AI alignment.

## Repository Structure

- **Master source:** `Uniform_Gnosis_Volume_I.md` — Markdown with YAML frontmatter. All content edits start here.
- **Build script:** `build.py` — generates EPUB and PDF from the Markdown master
- **Derived formats:** `.epub` (e-reader), `.pdf` (print-ready) — generated via `python3 build.py`
- **HTML version:** `Uniform_Gnosis_Volume_I.html` — interactive web reader, generated by `md_to_html.py`
- **SAIVAS reference card:** `Sentient_AI_Framework.html` — standalone visual summary of the framework
- **SAIVAS standards doc:** `SAIVAS.docx` — formal standards proposal
- **images/** — book illustrations (Gemini-generated PNGs, 7-9 MB each)
- **index.html** — redirect to the book HTML
- `.gitignore` uses a whitelist model (ignores everything, explicitly allows tracked files)

## Build Commands

```bash
python3 build.py              # Build all formats (html + epub + pdf)
python3 build.py html         # Build HTML only
python3 build.py epub         # Build EPUB only
python3 build.py pdf          # Build PDF only
```

The build script optimizes images (PNG→JPEG, resized to 1600px width) into a temp directory before generating output. Original PNGs in `images/` are not modified. HTML generation uses `md_to_html.py` which extracts CSS/JS from the existing HTML file so style tweaks are preserved across rebuilds.

## Content Workflow

When chapters are added or modified:

1. Edit `Uniform_Gnosis_Volume_I.md` (the master source)
2. Run `python3 build.py` to regenerate all formats (HTML, EPUB, PDF)
3. Update `README.md` chapter listing if structure changed
4. If adding new files, whitelist them in `.gitignore`

## Markdown Conventions

- YAML frontmatter with title, author, publisher, rights metadata
- `# PART NAME` for part headers, `## CHAPTER N` for chapter headings
- `### Section` (H3) and `#### Subsection` (H4) for within-chapter structure
- `<p class="separator">✦ ✦ ✦</p>` for section separators
- Images: `![alt text](images/Gemini_Generated_Image_N.png)` with `*Caption*` on next line
- `<div class="title-page">`, `<div class="copyright-page">`, `<div class="dedication">` for front matter

## HTML Book Architecture

`Uniform_Gnosis_Volume_I.html` is a single self-contained file (~230 KB) with all CSS/JS inline:

- **Sidebar navigation** with part/chapter links (`<a class="nav-link nav-chapter">`)
- **Chapter sections** use `<section id="chapter-N" class="chapter-section">` pattern
- **Headings:** `<h2 class="chapter-title">`, `<h3 class="section-heading">`, `<h4 class="subsection-heading">`
- **Dark mode** via `prefers-color-scheme` CSS media query
- The file has very long lines (content is minified-style) — use Python scripts for bulk edits, not sed/manual editing

## Key Dependencies (not in repo, installed locally)

- `pypandoc_binary` — Markdown to EPUB/DOCX conversion (bundles pandoc)
- `pillow` — image optimization during build
- `docx2pdf` — DOCX-to-PDF conversion (uses Word COM automation on Windows)
